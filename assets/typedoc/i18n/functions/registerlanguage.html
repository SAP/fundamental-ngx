• registerLanguage(lang, ...extraAliases): void

  • Register a language (and optional extra locale aliases) into the runtime registry. Call this at bootstrap via provideFundamentalTranslations() or provideAllFundamentalLanguages(). The language's own locale field is used as the primary key; additional aliases can be passed explicitly (e.g. 'zh-hans', 'zh').
