# Internal Documentation

**Purpose:** Maintainer and contributor guides for the Fundamental NGX project. These documents cover workflows, commands, and processes for developers working on the library itself.

> **Note:** This is **not** end-user documentation. For component usage guides and API docs, see the [docs app](../../apps/docs/) or visit [sap.github.io/fundamental-ngx](https://sap.github.io/fundamental-ngx).
