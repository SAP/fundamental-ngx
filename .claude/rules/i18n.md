# i18n Conventions (fundamental-ngx)

## Architecture

Signal-based internationalization. No async pipes needed.

```
FD_LANGUAGE_SIGNAL  (WritableSignal<FdLanguage>)  -- source of truth
        |
        |  derives via linkedSignal
        v
FD_LOCALE_SIGNAL    (WritableSignal<string>)      -- formatting locale
        |
        v
UI5 Bridge          (calls setLanguage())         -- opt-in via provideUi5LanguageBridge()
```

**Key principle:** Set `FD_LANGUAGE_SIGNAL` and let everything else derive. Only touch `FD_LOCALE_SIGNAL` for the rare case where formatting locale must differ from the language.

## API Patterns

```typescript
// Single translation (protected — used in template)
protected readonly label = resolveTranslationSignal('coreButton.label');

// Multiple translations via factory (factory is private, results are protected)
private readonly _translate = resolveTranslationSignalFn();
protected readonly submitLabel = this._translate('coreForm.submit');
protected readonly cancelLabel = this._translate('coreForm.cancel');

// Global language switch -- locale and UI5 follow automatically
this.langSignal.set(FD_LANGUAGE_GERMAN);
```

## Language Objects

Each `FdLanguage` carries `locale` and `name` metadata alongside translation keys. The `locale` field drives `FD_LOCALE_SIGNAL` via `linkedSignal`.

## Browser Auto-Detection

Enabled by default via `FD_LANGUAGE_AUTO_DETECT`. Resolution: exact match → Chinese region-to-script (`zh-CN` → `zh-hans`) → locale alias (`nb` → `no`) → base language (`pt-BR` → `pt`) → alias on base → English fallback. Only registered languages match steps 1–5.

## Adding / Renaming / Removing Keys

Use the CLI to add or remove keys — it updates both `translations.properties` and `fd-language.ts` automatically (`nx run i18n:i18n-manage --command=add|rename|remove`). The `/i18n-manage` skill has the full workflow.

For **rename**, update `fd-language.ts` manually first — the CLI does not handle interface updates for rename. Skipping this causes `TS2554: Expected 2 arguments, but got 1`.
