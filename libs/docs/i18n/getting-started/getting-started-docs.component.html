Step 1: Installation

The i18n package is part of fundamental-ngx. If you already have fundamental-ngx installed, you're all set!

If not, install it:

The @fundamental-ngx/i18n package includes pre-translated strings for 30+ languages including English, Spanish, French, German, Chinese, Japanese, and many more.

Step 2: Register languages your app supports

English works with zero setup. For any other language you must register it at bootstrap — otherwise a non-English LOCALE_ID falls back to English and logs a warning in development mode.

Use provideFundamentalTranslations to register only the languages your app supports (keeps the bundle small):

To restore the old all-languages behavior (larger bundle, no per-language work required), use provideAllFundamentalLanguages() instead. English-only apps need neither provider.

Where to find translation keys:

fundamental-ngx provides pre-translated strings for all its components. You can discover available translation keys in several ways:

  • Component documentation: Each component has an i18n section listing all its translation keys. For example, see Date Picker translation keys.
  • TypeScript autocomplete: Type 'coreDatePicker.' in your IDE and autocomplete will show all available date picker translations like dateInputLabel, dateRangeInputLabel, etc.
  • FdLanguage interface: Explore the FdLanguage type definition to see all available keys across all components.
Common translation keys:
  • coreDatePicker.dateInputLabel - "Enter date"
  • coreFileUploader.browse - "Browse"
  • platformTable.emptyTableMessage - "No data"
 Step 4: Use translations in TypeScript code

Sometimes you need translations in your TypeScript code (for tooltips, alerts, dynamic messages, etc.). Use the resolveTranslationSignal() function.

What's happening here:

  1. Import resolveTranslationSignal from @fundamental-ngx/i18n
  2. Call it with a translation key - this returns a signal (reactive value) containing the translated string
  3. Use () to invoke the signal and get the actual string value
  4. The translation automatically updates if the language changes!
