Message View Basic Usage

The message view component displays a list of error, warning, success, or information messages in a dialog.

Messages can be shown programmatically by passing an array of MessagePopoverErrorGroup objects to the component.

Each message can have a type (error, warning, success, information), a heading, and a description.

Action results in a dialog

Use Message View for results that describe an action and do not point to a field or table cell.

The app owns the message lifetime and clears its results when the dialog closes.
