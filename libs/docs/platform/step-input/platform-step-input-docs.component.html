Read-only Number Step Input Set [editable]="false" to mark Number Step Input as read-only. In read-only state the user must not be able to change the value: typing, the ArrowUp/ArrowDown keys and the increment/decrement step buttons are all blocked and must not mark the control dirty. Programmatic updates remain supported. This example uses both a template-driven (ngModel) and a reactive-form control.
