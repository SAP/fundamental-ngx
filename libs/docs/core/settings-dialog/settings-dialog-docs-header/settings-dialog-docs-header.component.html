Settings Dialog

The Settings Dialog allows users to personalize their Fiori experience by adjusting various settings. It follows a standard dialog layout, with a split content area. The left section displays a list of option groups, and selecting an option shows the corresponding settings in the detail area.

The Settings Dialog adapts to different screen sizes with three responsive modes:

  • Large (lg): Both list and detail areas visible side-by-side (≥1024px)
  • Medium (md): Shows one area at a time with back navigation (600-1023px)
  • Small (sm): Shows one area at a time with back navigation (<600px)


Settings Dialog building blocks
  • fd-settings is the Settings root container. Applied as an attribute directive to the dialog content container.
  • fd-settings-container is the main container component that manages the split-view layout, responsive behavior, and view stack navigation.
    • detailsAreaTitleHeading sets the heading level (1-6) for the detail area title. Default: 2
    • detailsAreaTitleHeadingSize sets the heading display size (1-6) for the detail area title. Default: 5
    • backBtnAriaLabel sets the aria-label for the back navigation button (required for accessibility in md/sm modes)
    • Programmatic methods: pushView(template, title), popView(), clearViewStack() for drill-down navigation within settings sections
  • fd-settings-dialog-body wraps the entire settings content and applies the dialog body styling.
  • fd-settings-dialog-content is the content wrapper that contains both list and detail areas.
  • fd-settings-list-area marks the left section containing the navigation list of settings categories.
    • Use with fd-list component with [settingsList]="true" property
    • Each fd-list-item requires [settingsListTpl] input linking to the template to render in the detail area when selected
    • Optional footer: use fd-list with [settingsListFooter]="true" for footer items (e.g., Help, About)
  • fd-settings-detail-area marks the right section where the selected setting's content is displayed.
    • Contains a header with back button (md/sm modes only) and title
    • Content area renders the template linked via settingsListTpl
  • fd-settings-header styles the detail area header. Applied automatically by fd-settings-container.
  • fd-settings-header-button marks the back navigation button. Visible only in md/sm modes. Automatically managed by fd-settings-container.
  • fd-settings-content-container wraps the scrollable content in the detail area.
  • fd-settings-content marks individual content sections within the detail area.
  • fd-settings-spacing provides consistent spacing between content sections. Includes size input: 'small' | 'medium' | 'large' | 'form'
  • fd-settings-list-container wraps list content within settings sections (e.g., preference lists within a category).
  • Profile Card directives for user profile display:
    • fd-settings-profile-card wraps the profile card container
    • fd-settings-profile-card-name marks the user name element
    • fd-settings-profile-card-subline marks secondary information (e.g., email, role)

Integration with other components
  • Dialog: Add settings: true to the dialog configuration object to apply settings dialog styling
  • Bar: Used for the dialog header bar
  • Title: Used for dialog title and detail area titles
  • List: Requires settingsList and settingsListFooter boolean properties
  • List Item: Requires settingsListTpl input property linking to detail area template
  • Icon Tab Bar: Add settings boolean property for settings-specific styling
  • Input Group: For search/filter functionality in the list area

Usage Patterns
  • User Account View: Use the Profile Card directives (fd-settings-profile-card, fd-settings-profile-card-name, fd-settings-profile-card-subline) to display user information like name, email, and role at the top of the User Account settings section.
  • Spacing between content: Use fd-settings-spacing with size input ('small' | 'medium' | 'large' | 'form') to add consistent spacing between sections. Common use cases:
    • Notifications view: Add spacing between form items using <div fd-settings-spacing size="form"></div>
    • Message strips: Add spacing after message strip components using <div fd-settings-spacing size="medium"></div> (or other size as needed)
