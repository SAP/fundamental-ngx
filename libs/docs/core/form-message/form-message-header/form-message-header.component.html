Form Message
The form message is a feature that is used as an information bar. It contains information about an object or a status and can be embedded within the detail area of an object or page. The form message cannot act as a stand alone component.

Accessibility

Form messages are announced to screen readers with aria-live="assertive" and aria-atomic="true", ensuring assistive technologies immediately announce changes.

  • Automatic ARIA linking: When using fd-form-input-message-group, the component automatically links the form control to the message using the appropriate ARIA attributes:
    • For error messages: sets aria-invalid="true"
    • For information/warning/success/error messages: sets aria-describedby (pointing to the message ID)
    If you don't provide an id on the form message, a unique default value is automatically assigned.
  • Value state announcement: Each message type displays an icon that needs a text alternative for screen readers. The component automatically provides translated screen reader text that describes the icon's meaning:
    • Error: "Invalid Entry"
    • Warning: "Warning"
    • Success: "Success"
    • Information: "Information"
    You can override the default text by setting the valueStateMessage input if you need context-specific announcements (e.g., "Invalid email format" instead of generic "Invalid Entry").
