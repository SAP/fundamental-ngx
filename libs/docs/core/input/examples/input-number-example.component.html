Number Input Features

Value & Placeholder

The numeric input always displays a value when not in active state. The value is a rational number. The default value is 0. If a minimum or maximum value is defined, the default is the closest value to 0. When no value is set, on focus out the field is empty. Applications can set an initial value. While the field is active and the value has been cleared, placeholder text can be displayed.


Reset

When the Escape key is pressed while the numeric input is in active state, the value that was set before the field became active is restored.

Step Size

A step size can be set, defined as a rational number that is added or subtracted from the current value when the value is increased or decreased via keyboard or scroll. Use step attribute/property to define the step size.


Larger Step Size

A larger step size can be set, defined as a rational number. When pressing Page Up/Down keys, the current value is increased or decreased by the product of the step size multiplied by the larger step size.


Step Mode

The step mode defines how the new value is calculated when stepping:

  • Addition and subtraction — the new value results from adding or subtracting the step size from the current value.
  • Multiple — the new value results from rounding the current value to the nearest multiple of the step size. Set stepMode="multiple" to enable this mode.

Minimum & Maximum Value

Minimum and maximum values can be set as rational numbers. When the value reaches the minimum or maximum, the Up/Down keyboard shortcuts are disabled at that boundary. If a value outside the range is entered, an error state appears. When adding or subtracting a step size would exceed the minimum or maximum, the value is set to the minimum or maximum instead.

Value Precision

The number of digits after the decimal point can be defined as a natural number, including 0. When typing or pasting a value, digits exceeding the defined precision are not accepted and an error state appears briefly. Use the valuePrecision property to set the precision.

Value Alignment

The value can be aligned within the input field. End alignment is the default and is recommended for easier comparison of numbers. Use the valueAlignment property to set the alignment.


Thousands Separator

Large values can be grouped using thousands separators to improve readability. Set the thousandsSeparator property to enable this feature.

International Number Format

Numbers can be displayed in an international format, which may include different grouping and decimal separators based on locale. Use the numberLocale property to specify the desired locale.
