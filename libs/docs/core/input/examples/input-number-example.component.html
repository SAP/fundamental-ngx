Basic Numeric Input Validation

The input only accepts valid numeric characters: digits (0-9), minus sign (-), decimal point (.), and scientific notation (e/E). Try typing letters or special characters - they will be blocked.

Try: Type letters (blocked), special characters like @ # $ (blocked), valid numbers like 123.45 (accepted), negative numbers like -99 (accepted), scientific notation like 1e5 (accepted)

Value & Placeholder

The numeric input always displays a value when not in active state. When no value is set, on focus out the field is empty.

Instructions: Click input → Delete → See placeholder → Press Enter → Input shows 0

Reset (Escape Key)

When the Escape key is pressed while the numeric input is active, the value before focus is restored.

Instructions: Input shows 50 → Delete → Input shows placeholder → Press Escape → Input shows 50 again

Step Size

A step size defines the increment/decrement value when using arrow keys or scroll.

Instructions: Use Arrow Up/Down keys or scroll to increment/decrement by 1

Instructions: Use Arrow Up/Down keys to increment/decrement by 5 (3 → 8 → 13)

Larger Step Size

Page Up/Down keys increase or decrease the value by (step × largeStep).

Instructions: Arrow Up = +1, Arrow Down = -1, Page Up = +10, Page Down = -10. Start at 0 → Arrow Up → 1 → Page Up → 11

Instructions: Step = 5, larger step = 3. Start at 0 → Arrow Up → 5 → Page Up → 20 (5 + 5×3)

Step Mode - Multiple

In 'multiple' mode, values round to the nearest multiple of the step size.

Instructions: Start at 1 → Arrow Up → 5 (rounds to nearest multiple of 5) → Arrow Up → 10 → Arrow Down → 5

Instructions: Start at 3 → Page Up → 15 (3 + 15 = 18, rounds to 15) → Page Down → 0

Min & Max Value

Minimum and maximum values enforce boundaries. Values outside the range show an error state.

Instructions: Try entering 0 or 11 to see error state. Arrow keys stop at boundaries.

Value Precision

The number of digits after the decimal point can be defined.

Instructions: Try entering 3.14159 → blur → displays as 3.14 (2 decimals)

Validation Mode - Live

Live validation validates immediately on each keystroke.

Instructions: Type 150 → error appears immediately as you type

Value Alignment

The value can be aligned within the input field. End alignment (right in LTR) is the default.

Thousands Separator

Large values can be grouped using thousands separators to improve readability.

Instructions: Enter 1000000 → blur → displays as 1,000,000

Internationalization (i18n)

Decimal separator can be configured for different locales.

Instructions: Decimal separator is comma (e.g., 1.234,56 instead of 1,234.56)
