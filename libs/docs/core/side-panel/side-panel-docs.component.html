Basic usage Use the fd-side-panel component with one fd-side-panel-item per content group. Each item contributes one button to the vertical action bar in the default collapsed mode, where [icon] is the button glyph and [label] is the group name shown as a tooltip on hover and on keyboard focus. Use [side] ('left' | 'right') to anchor the bar and bind [(activeItem)] to track the selected group — clicking a button activates its group and clicking it again clears the selection. The nav arrow toggles the bar between 'collapsed' (icons only) and 'expanded' (320px wide with labels). Group content is projected through *fdSidePanelContent and appears in the content panel when the group is active. Counters Use [counter] to show a numeric badge at the top-right corner of the action button. Values above 99 are automatically capped and displayed as 99+. The badge works in both collapsed and expanded mode. Single action When the side panel contains exactly one fd-side-panel-item, it enters single-action mode automatically. In this mode no action button is shown — only the nav arrow, which directly opens and closes the content panel. Bind [(open)] to track the panel state. The single item's label is displayed next to the nav arrow when the bar is in 'expanded' mode. Overflow When more fd-side-panel-item elements are projected than the action bar can display at its current height, a ••• overflow toggle button appears automatically at the bottom of the visible items. No inputs or configuration are required — overflow is detected via a ResizeObserver and is entirely automatic. Clicking the toggle opens a floating list showing the hidden items with their icon and label. Clicking an item from the list activates it and closes the list. The overflow list supports keyboard navigation: use ArrowDown / ArrowUp to move between items, Enter or Space to activate, and Escape to close and return focus to the ••• button. Resizable Set [resizable]="true" on fd-side-panel to enable the resize splitter. The content panel can then be resized by dragging the splitter bar on its inner edge, with the Arrow keys (Shift+Arrow for larger steps) while the bar is focused, or via the width menu (right-click the bar or press Shift+F10): Expand to Maximum Width, Collapse to Minimum Width, Reset to Default Width. Use defaultWidth, minWidth, and maxWidth to control the initial and clamped sizes.
