Basic usage Use the fd-side-panel component with one fd-side-panel-item per content group. Each item contributes one button to the vertical action bar in the default collapsed mode, where [icon] is the button glyph and [label] is the group name shown as a tooltip on hover and on keyboard focus. Use [side] ('left' | 'right') to anchor the bar and bind [(activeItem)] to track the selected group — clicking a button activates its group and clicking it again clears the selection. The nav arrow toggles the bar between 'collapsed' (icons only) and 'expanded' (320px wide with labels). Group content is projected through *fdSidePanelContent; opening the content panel is added in a later release. Counters Use [counter] to show a numeric badge at the top-right corner of the action button. Values above 99 are automatically capped and displayed as 99+. The badge works in both collapsed and expanded mode. Single action When the side panel contains exactly one fd-side-panel-item, it enters single-action mode automatically. In this mode no action button is shown — only the nav arrow, which directly opens and closes the content panel. Bind [(open)] to track the panel state. The single item's label is displayed next to the nav arrow when the bar is in 'expanded' mode.
