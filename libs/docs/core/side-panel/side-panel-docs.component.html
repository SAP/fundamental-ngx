Basic usage Use the fd-side-panel component with one fd-side-panel-item per content group. Each item contributes one button to the vertical action bar in the default icons-only mode, where [icon] is the button glyph and [label] is the group name shown as a tooltip on hover and on keyboard focus. Use [side] ('left' | 'right') to anchor the bar and bind [(activeItem)] to track the selected group — clicking a button activates its group and clicking it again clears the selection. Group content is projected through *fdSidePanelContent; opening the content panel is added in a later release.
