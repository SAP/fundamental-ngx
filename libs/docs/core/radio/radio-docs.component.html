Radio Button States Radio Button Reactive Forms

Bind every option in a group to the same formControlName and name, and give each a different value. This component also requires selectedValue to match the control's current value.

Set disabled state on the form control when you create it, or call disable() and enable(). Disabled radios are skipped during keyboard navigation. In an enabled FormGroup, disabled controls are left out of value; use getRawValue() to include them. If the whole group is disabled, value includes its controls.

Read-only radios stay focusable but prevent users from changing the selection. Programmatic updates and reset still work. Reset clears a nullable control; a nonNullable control resets to its initial value.

Radio Button Text Truncation By default, long radio label truncates with ellipsis. For this behaviour no modifier class or property is needed. For radio label that wraps on a new line to show the entire content, set the wrapLabel property to true. For a top-left aligned label with wrap behaviour, set the wrapLabel property to true and specify valignLabel="top".
