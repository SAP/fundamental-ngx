Basic Product Switch (App Launcher) inside Shellbar. Product switch (App Launcher) with enabled Drag And Drop. The DnD functionality can be switched off by passing [dragAndDropEnabled]="false" to component. The event thrown on drop can be handled by binding to (productsChange). The element can stick to it's position, it can be achieved by passing stickToPosition: true value to the interface object. Example of usage is in Home product. Use (isOpenChange) to listen for open/close state changes.

SAP Start must be the first item. The panel always focuses the first product on open. By convention, the first entry in the products array must be the SAP Start product so that focus lands there consistently. Large Product Switch (App Launcher) is displayed with a maximum of 4 columns on large desktop screens. Beyond the fourth row, a vertical scroll bar is introduced. Medium If there are 6 or fewer items to display, it is recommended to use the 3-column layout (medium). The component automatically switches to 3 columns when it detects fewer than 7 products. Two-Column Layout When fewer than 3 items are provided, the component automatically switches to a 2-column layout that hugs its contents, matching the spec for small product sets. List Mode For narrow screens the Product Switch (App Launcher) transforms to a List by itself. Add the [forceListMode]="true" to force the list layout, even on larger screens. Busy State Pass [busy]="true" to show a loading indicator over the product list while items are being fetched. The busy indicator is removed once the products array is populated. URL Navigation When a product item has a url, clicking it navigates to that URL. The default target is _blank (opens in a new tab). Override with target: '_self' for same-tab navigation, or target: '_parent' / target: '_top' for frame contexts. Items without a url fire the callback instead.
