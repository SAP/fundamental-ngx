Default Tooltip Add fdTooltip="..." to any element. The tooltip shows after 500 ms on mouse hover or keyboard focus and hides 500 ms after the pointer or focus leaves. Clicking an element moves focus to it without showing the tooltip; activating the element (click or Enter) or clicking anywhere else hides it immediately. Only one tooltip is visible at a time: move between the icon buttons to see the previous tooltip close at once and the next one open after 200 ms. On touch devices, a long-press shows the tooltip; on links it is disabled so the native context menu still works. Placement and Alignment Use fdTooltipPlacement (top by default, bottom, left, right) and fdTooltipAlignment (start, middle by default, end). When there is not enough room, the tooltip flips to the opposite side — scroll the page so a button is at the top edge of the viewport to see it. Keyboard Shortcuts and Accessibility

The tooltip text is exposed to screen readers through aria-describedby, but only when it adds information to the element's accessible name. Existing aria-describedby references are kept.

Put the shortcut at the end of the text in parentheses, e.g. Save (Ctrl+S), and pass it in aria-keyshortcuts format via fdTooltipKeyShortcuts="Control+S". The shortcut is then announced through aria-keyshortcuts and left out of the description.

With a button focused, press Ctrl + Alt + I to toggle its tooltip without delay and Esc to close it. The table shows the resulting attributes.

Truncated Text Use a tooltip to reveal truncated text only when other patterns, like wrapping, cannot be applied. Enable it only while the text is actually truncated by binding [fdTooltipDisabled]. In this example, the text also becomes focusable only while truncated, so keyboard users can reach the tooltip. Dynamic Text and Disabled State The tooltip text can change at any time. Set [fdTooltipDisabled]="true" or pass an empty text to disable the tooltip. A disabled tooltip adds no attributes or event listeners to the host element. Custom Delays Override the delays for a single tooltip with [fdTooltipShowDelay] and [fdTooltipHideDelay] (in milliseconds), or for a whole application or component by providing TOOLTIP_CONFIG with any of showDelay, hideDelay and sequenceDelay. This example provides {{ '{' }} showDelay: 1000 {{ '}' }}. Programmatic Control Get the directive instance with #ref="fdTooltip" and call show() or hide() to open or close the tooltip immediately. Tooltip in a Dialog When a tooltip is open, the first Esc only closes the tooltip; the dialog stays open and closes on the next Esc. Switching to another browser tab or window also closes the tooltip, and it is not restored when you come back.
