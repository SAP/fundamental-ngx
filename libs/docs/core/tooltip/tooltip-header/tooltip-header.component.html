Tooltip

A tooltip is a short, non-disruptive text popup that describes the element it is attached to. Add the fdTooltip directive to any existing element — no wrapper or DOM changes are needed. The tooltip is rendered with the popover overlay, so it gets the same positioning, viewport flipping and arrow.

  • Shows after a delay on mouse hover or keyboard focus, and immediately on touch long-press.
  • Only one tooltip is visible at a time. Moving to the next element shows its tooltip after a shorter delay.
  • The tooltip can be hovered and its text selected; focus always stays on the host element.
  • Esc closes the tooltip without closing the surrounding dialog, Ctrl + Alt + I toggles it on the focused element.
Use tooltips for short, supplementary text only. For rich, interactive or long content use a Popover; for help text next to form labels use Inline Help. Never put information that is required to complete a task into a tooltip.
