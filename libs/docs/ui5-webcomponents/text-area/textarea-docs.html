Basic Sample Growing Enable the growing property to make the textarea automatically expand with content. Use rows to set the initial size and growingMaxRows to limit maximum expansion. This provides a better user experience by adapting to content size. Character Counter Modes Use counterMode with maxlength to control the character counter and limit behavior. None hides the counter and applies a hard limit. Auto reveals the counter on focus, overflow, or critical/negative value states while reserving its space. Always keeps the counter visible and supports a soft limit. Value States TextArea supports different visual states to communicate status to users: None (default), Positive (success), Critical (warning), Negative (error), and Information. These states provide visual feedback for validation and user guidance. TextArea can also be disabled or readonly. Events TextArea emits various events for different interactions: ui5Change (on focus out), ui5Input (on each keystroke or when something is pasted), ui5Select (on text selection), and ui5Scroll (on content scrolling). Use these events for responsive user interactions.
