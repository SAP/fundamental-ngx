Input Input component examples with various configurations including validation states, value binding, and reactive forms integration Autofocus The autofocus attribute automatically focuses the component when the page loads or when it appears in a dialog/popover. This is useful for forms and dialogs where you want to direct user attention to a specific input. Interactive Icons Use ui5-input-icon in the icon slot to add interactive icons to an input field. Unlike a static ui5-icon, ui5-input-icon is focusable and fires a ui5Click event when activated with a click, Enter, or Space. Common patterns include a search trigger and a clear button that appears only when the input has a value. Always set accessibleName so screen readers can announce the icon's purpose independently of the input's label.
