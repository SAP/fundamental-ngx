Basic Dynamic Date Range The basic Dynamic Date Range allows users to select predefined date ranges using natural language options. Click the input field to open the popover and choose from available date range options like "Today", "Tomorrow", "Yesterday", etc. Value Object Handling The Dynamic Date Range returns a structured value object containing the operation type and related data. This example demonstrates how to access and interpret the value object, including extracting actual date ranges for different operation types. Label Association As of v2.25.0, ui5-dynamic-date-range supports explicit label association. Use a ui5-label with a matching for attribute, or set the accessibleNameRef input directly to the id of a label element. Both approaches ensure screen readers announce the label when the component receives focus.
