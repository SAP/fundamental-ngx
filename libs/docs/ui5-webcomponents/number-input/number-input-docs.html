Basic Number Input The Number Input component is a numeric input field that allows users to enter, edit, and select numeric values. Use the value property to control the current value. The step property defines the increment when using the increase/decrease buttons or keyboard navigation (default is 1). The ui5Change event fires when the value changes. Min and Max Values The Number Input supports min and max properties to restrict the allowed range. The increase/decrease buttons and keyboard navigation become disabled when the value reaches the limits. Users can still manually enter values outside the range, but validation will indicate the error. Value Precision The Number Input supports decimal values with configurable precision using the valuePrecision property. This controls how many decimal places are displayed and accepted. States The ui5-number-input component supports several semantic value states, read-only mode, and disabled mode.
